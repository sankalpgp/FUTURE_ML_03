# Resume / Candidate Screening System (Machine Learning & NLP)

A machine learning project that automatically screens and ranks resumes based on job description relevance.  
The system uses **Natural Language Processing (NLP)** and **similarity scoring techniques** to evaluate candidate-job fit.

---

## Project Objective

Automated resume screening helps organizations:

- Shortlist candidates faster  
- Match skills with job requirements  
- Reduce manual recruiter effort  
- Improve hiring consistency  
- Identify missing skills  

This project demonstrates how machine learning supports **real-world recruitment decisions**, not just model training.

---

## Dataset

**Sample – Resume & Job Description Data**

- Unstructured text-based resumes  
- Job descriptions containing role requirements  
- Multiple skill categories and keywords  
- Suitable for NLP and text analysis  

The system works with resume text and job role descriptions.

---

## Tech Stack

- Python  
- Pandas, NumPy  
- spaCy  
- NLTK  
- Scikit-learn  
- Matplotlib  

---

## Workflow

1. Load resume and job description data  
2. Clean and preprocess text  
3. Perform tokenization and normalization  
4. Extract skills and keywords using NLP  
5. Convert text into numerical vectors  
6. Compute resume-job similarity scores  
7. Rank candidates based on relevance  
8. Identify missing or weak skills  

---

## Machine Learning Approach

**Text Vectorization & Similarity Scoring**

- TF-IDF / Bag-of-Words for feature extraction  
- Cosine similarity for resume matching  
- NLP-based skill and keyword analysis  

Designed for interpretability and decision support.

---

## Evaluation Logic

Candidate relevance is determined using:

- Skill overlap  
- Keyword matching  
- Resume-job similarity score  

Higher similarity indicates stronger role alignment.
